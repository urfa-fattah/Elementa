About Elementa

The story behind the interactive periodic table

The Project

Elementa is a modern, interactive periodic table built to make learning about the chemical elements intuitive and enjoyable. Launched in 2025, it displays all 118 confirmed elements with smart search, category filters, detailed property views, and side-by-side comparisons. Whether you're a student, teacher, or just curious about the building blocks of matter, Elementa provides a clean, calm space to explore chemistry.

Why We Built It

We wanted to offer a free, beautiful resource that transforms the classic periodic table into an interactive journey. The goal is to make chemistry feel less intimidating and more like an exploration—whether you’re studying, teaching, or simply satisfying your curiosity.

How It’s Built

Elementa runs on plain HTML, CSS, and JavaScript, with React powering the main table. Element data is fetched from a lightweight JSON file, charts use Chart.js, and the entire project is hosted on Netlify. The interface adapts seamlessly to any device, with an optional light/dark theme for comfortable reading.
